# {{projectName}}

A SvelteKit starter powered by the Svelte Visual Builder.

## Development

```bash
pnpm install
pnpm dev
```

Open the editor at `http://localhost:5173/` and the published page at
`http://localhost:5173/published/home`.

## Build

```bash
pnpm build
```

The starter keeps projects in memory. Replace `src/lib/server/host-store.ts`
with your database or CMS before deploying.
